# Окружение для разработки

## Корневая директория
После установки VRack2 все проекты, разрабатываемые в рамках **VRack2 Core**, располагаются в директории:
```
/opt/vrack2-service
```

Несмотря на то, что проектов у вас может быть много - но разрабатываться они могут все в одной директории `vrack2-service`. 

## IDE: code-server
Для разработки подойдёт любая среда, но самый быстрый способ начать — использовать **code-server** (VS Code в браузере).

### Установка (Linux)
```bash
curl -fsSL https://code-server.dev/install.sh | sh
```

### Запуск
```bash
code-server --auth=none --bind-addr=0.0.0.0:8888
```

### Доступ
Откройте в браузере:

```
http://<адрес-сервера>:8888
```

Перейдите в `/opt/vrack2-service` — можно приступать к разработке.
